## ✨ Fitur Undangan
- **Responsive & Mobile-first**: Tampilan optimal di smartphone maupun desktop.
- **Background Music**: Musik otomatis aktif saat tombol "Buka Undangan" ditekan (`song.mp3`).
- **RSVP & Buku Tamu Realtime**: Konfirmasi kehadiran dan ucapan doa restu langsung tersimpan ke Google Sheets.
- **Amplop Digital**: Fitur salin nomor rekening Bank Mandiri, BSI, dan GoPay.
- **Love Story Timeline**: Perjalanan kisah cinta mempelai.
- **Google Maps**: Peta petunjuk lokasi acara.

## 🚀 Panduan Deploy GitHub Pages
1. Masuk ke tab **Settings** di repositori GitHub ini.
2. Pilih menu **Pages** di panel sebelah kiri.
3. Pada bagian **Build and deployment > Branch**, pilih branch `main` dan folder `/ (root)`.
4. Klik **Save**. Tunggu beberapa saat hingga URL website undangan aktif.
